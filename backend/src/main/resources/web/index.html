Como funciona

Mova o mapa ou aproxime o zoom para explorar outra área. As cores indicam a qualidade do pavimento nos trechos medidos, e os marcadores mostram a localização aproximada de buracos e lombadas. Selecione um trecho ou marcador para ver os detalhes.
